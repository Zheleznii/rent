# Прокат транспорта – Техническое задание

## Функциональные возможности

- Авторизация сотрудников (роли: Менеджер, Оператор станции, Техспециалист, Контроллёр, Бухгалтер). Хранение паролей в виде хеша.
- Управление клиентами – просмотр, добавление, редактирование, удаление.
- Управление транспортом (авто, вело, гироскутер, мото) – просмотр, добавление, редактирование, удаление, фильтр по типу и станции.
- Управление станциями – просмотр, добавление, редактирование, удаление.
- Управление тарифными планами – просмотр, добавление, редактирование, удаление.
- Оформление и завершение аренды, автоматический расчёт штрафа при превышении времени, смена ТС в рамках тарифа.
- Отслеживание активных аренд и истории.
- Учёт доходов (аренда, штрафы) и расходов (топливо, ремонт, зарплаты). Финансовый отчёт.
- Поиск и фильтры по клиентам, транспорту, арендам.
- Два способа работы с БД: сырые SQL-запросы и ORM (Entity Framework Core).

## Архитектура

Клиент-серверная модель:

- **Сервер** – консольное приложение на C#.
  - Бизнес-логика проката.
  - Работа с БД (MS SQL Server).
  - TCP-сокеты, обмен JSON.
- **Клиент** – WPF приложение.
  - Отправка запросов на сервер.
  - Отображение данных, ввод пользователя.
